Mandouby (مندوبي)

Mandouby is a private class assistant for the Mechatronics and Robotics (MCTR) cohort at the Faculty of Engineering, Ain Shams University. It answers schedule and bylaw questions in the class chats and files class material into the cohort's shared Google Drive.

It is run by the class coordinators and is not a public service.
